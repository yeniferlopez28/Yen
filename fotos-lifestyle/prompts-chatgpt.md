# Prompts para ChatGPT: fotos lifestyle FIBO

## Cómo usarlos

1. En cada chat nuevo de ChatGPT adjunta dos imágenes, en este orden:
   - **Imagen 1:** el empaque real del sabor (`assets/fibo-brownie.webp`, `fibo-chocolate.webp`, `fibo-cookies.webp` o `fibo-frutos.webp`).
   - **Imagen 2:** la foto de referencia de estilo que se indica en cada prompt.
2. Pega el prompt tal cual. Formato vertical 4:5 (en ChatGPT: "vertical").
3. Si el texto del empaque sale deformado, manda en el mismo chat el **prompt de corrección** del final.
